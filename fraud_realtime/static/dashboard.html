Getting started
Step 1
Install dependencies: pip install -r requirements.txt
Step 2
Start the API: python -m uvicorn app.main:app --port 8000 --reload
Step 3
Run the simulator: python stream_simulator.py --demo --rate 5
Step 4
For real scoring: copy stacked_ensemble.joblib + scaler.joblib to models/
